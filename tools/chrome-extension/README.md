# Расширение «В чтение»

Кнопка на панели браузера: открытая статья → вкладка «Чтение» в Задачах.

Поставить (Chrome, Edge, Яндекс.Браузер, Opera — одинаково):
1. Открыть `chrome://extensions` (в Edge — `edge://extensions`, в Яндексе — `browser://extensions`).
2. Включить «Режим разработчика» (справа вверху).
3. «Загрузить распакованное расширение» → выбрать эту папку (`Task meneger\tools\chrome-extension`).
4. Значок пазла 🧩 на панели → булавка у «В чтение», чтобы кнопка всегда была видна.

Папку не удалять и не переносить — браузер берёт расширение из неё.
После изменения файлов расширения — на `chrome://extensions` нажать ↻ у него.
